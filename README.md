# Chapter17_GridGame

A C++ grid-based game implementation featuring CMake build configuration.

## Project Overview

This project is a grid game developed in C++ with a modern CMake build system. It demonstrates game development concepts using a grid-based gameplay mechanic.

## Build Requirements

- C++ compiler (C++11 or later)
- CMake 3.10 or higher

## Build Instructions

```bash
mkdir build
cd build
cmake ..
make
```

## Running the Game

After building, run the executable from the build directory:

```bash
./Chapter17_GridGame
```

## Project Structure

- **Source Code**: Written in C++ (94.9% of the codebase)
- **Build Configuration**: CMake (5.1% of the codebase)
